# Gate screen recordings

Place one MP4 beside this file for each gate:

- `sensitive-information.mp4`
- `dependency-risk.mp4`
- `model-catalog.mp4`
- `intent.mp4`
- `trending-cost.mp4`

The presentation generator automatically embeds a recording when the expected
file exists. Otherwise it renders the gate's command and expected outcomes in a
terminal-style recording frame.

Record only the prepared scripted demos. Use an isolated terminal window, hide
notifications and unrelated tabs, and keep credentials, real PII, personal
session data and raw sensitive fixtures off screen. Begin with the command
already typed, run it once, and end on the safe summary output or receipt.
